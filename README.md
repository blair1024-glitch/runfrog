# 呱踏騎單車

一隻樹蛙騎著腳踏車在鄉間小路上奔馳的 2D 跑酷小遊戲。整個遊戲就是一個 HTML 檔，不需要安裝任何東西。

## 怎麼玩

- **跳躍**：空白鍵、↑ 或點畫面（手機直接點）。在空中可以再跳一次（二段跳）
- **暫停**：P 或 Esc
- **車鈴**：B

跳過石頭、三角錐、木頭和木箱；兩層高的木箱堆要用二段跳。蒼蠅靠近時青蛙會自動伸舌頭吃掉，每隻 +50 分。撞到三次就摔車結束。速度會越來越快，白天、黃昏、夜晚也會自動輪替。

## 執行

直接用瀏覽器打開 `index.html` 即可。

也可以開啟 GitHub Pages（Settings → Pages → Branch: `main` / root），就會得到一個可以分享的網址。

## 技術

- HTML Canvas 2D 繪圖，多層視差捲動
- 雙關節逆向運動學讓腳踩著踏板
- Web Audio API 合成音效
- 最高分記在瀏覽器的 localStorage
